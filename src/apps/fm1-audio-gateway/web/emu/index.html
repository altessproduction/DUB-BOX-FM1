DUB-BOX — LA STATION DUB SUR FM-1

Tout ce qui suit est le vrai firmware — le même que sur le FM-1, compilé en WebAssembly. DUB-BOX est la carte son USB et le récepteur Bluetooth du FM-1 (le routeur audio), avec les modules dub de sloop-DUB portés dessus : la sirène, le tape echo, le filtre DJ et l'isolateur sur leurs pages. OCT− ouvre l'écran DUB : cinq pages, DUB · SIREN · SIREN 2 · DELAY · ISO — les pages de sloop-DUB, chaque page règle ses quatre réglages sur K1–K4. PLAY rend le master muet — le drop. Les touches noires sont la performance, depuis n'importe quel écran : les quatre premières tuent les bandes de l'ISO, la dernière est la gate de la sirène — tenue, elle chante ; relâchée, elle s'arrête, et sa queue continue de sonner dans le delay. Les réglages survivent au rechargement de la page.

LES CINQ PAGES DUB — OCT− POUR ENTRER

  • DUB — K1 le filtre DJ (bipolaire : passe-bas à gauche, passe-haut à droite, FLAT au crantage central, les balayages glissent), K2 le mix, K3 le throw vers le tape echo. SEL change de module.
  • SIREN — comme la page SIR de sloop-DUB : K1 le type de LFO (WAIL, HILO, RAMP, SWEEP, SPACE), K2 la forme (SQR, PLS, SAW, TRI, SIN), K3 la hauteur 220–1200 Hz, K4 le send — l'envoi de la sirène dans le tape echo (0 = DRY ; c'est lui qui laisse sa queue sonner après le relâchement). La dernière touche noire est sa gate : tenue elle chante, relâchée elle s'arrête — depuis n'importe quel écran. REC n'a rien à voir avec elle, SEL tourne aussi la forme.
  • SIREN 2 — comme la page SR2 de sloop-DUB : K1 la vitesse 1–16 Hz, K2 la profondeur (l'amplitude du balayage de hauteur, deux octaves à 127), K3 la symétrie du LFO, K4 le niveau — ce que la dernière touche noire fait sonner.
  • DELAY — le tape echo : K1 le temps 40–740 ms, K2 le feedback, K3 le niveau, K4 le ton (l'amortissement des répétitions). Le temps glisse comme une bande qui satellite, les têtes ondulent (wow 0,7 Hz, flutter 6,3 Hz), les répétitions passent dans l'amortissement et une saturation douce qui chauffe passage après passage.
  • ISO — quatre bandes SUB 90 · BASS 420 · MIDS 2600 · TOPS : K1/K2/K3/K4 leurs gains −24…+12 dB, les 4 premières touches noires (OP1–OP4) les tuent, leur LED s'allume tant que la bande est basse ; les quatre ensemble, c'est le total kill, et un kill réveille le module s'il dormait. SEL relève tous les kills.

LE ROUTEUR DESSOUS — LE SON QUI TRAVERSE

  • Le beat du navigateur (ou votre fichier, ou le micro) entre par le port USB émulé : exactement le trajet d'un DAW sur le vrai FM-1 — trims, gates, mix, EQ, limiteur, master.
  • GLO ouvre le mixer : quatre tranches USB IN / BT IN / USB OUT / MASTER, mute et solo.
  • FX : l'EQ cinq bandes et le limiteur, avec leurs préréglages.
  • EDIT : les réglages (l'échantillonnage du master, les codecs Bluetooth, l'écran…). SAVE s'allume quand un brouillon attend.
  • OCT+/OCT− hors de l'écran DUB : le codec et les pages.

SOURCES, BLUETOOTH, MÉMOIRE

  • Le beat dub intégré : un one-drop 74 BPM synthétisé par la page — la matière à dubber, sans rien installer.
  • Le récepteur Bluetooth reste hors ligne dans l'émulateur (pas de radio) : ses menus se parcourent, mais aucun téléphone ne vient y jouer. Sur le vrai FM-1, il reçoit SBC, AAC, aptX et aptX HD.
  • Les réglages et presets sont gardés dans ce navigateur (objets sauvegardés et zone de données, comme le flash du FM-1 garde les siens). Factory reset oublie tout ; les boutons de la barre (image, MIDI, restart) viennent des parts de l'émulateur fm1-base.
  • Copy session copie ce que vous avez joué en script du simulateur — collez-le dans un rapport de bug : il rejoue votre session dans le simulateur hôte du dépôt.
